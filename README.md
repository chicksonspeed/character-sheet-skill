# Character Sheet Generator

Interactive Grok skill for generating professional character reference sheets (Will-style layout) from uploaded photos and character info.

## Contents
- `SKILL.md` — Main skill instructions
- `CHANGELOG.md`
- `evals/` — Test cases and triggers

## Install
Copy the contents into your Grok skills directory (e.g. `/root/.grok/server-skills/character-sheet/`).
