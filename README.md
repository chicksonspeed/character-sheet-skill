# Character Sheet Generator

Web app for generating professional Will-style character reference sheets.

Fill in character details, upload reference photos, and get a strict-layout prompt ready to paste into Grok, Flux, Midjourney, or any image generator.

## Live App

Once GitHub Pages is enabled, the app will be available at:

**https://chicksonspeed.github.io/character-sheet-skill/**

## Local

Just open `index.html` in a browser.
