# RefSheet

Web app for building professional character reference sheets. Download a zip you can drop into any image model.

**Live:** https://chicksonspeed.github.io/refsheet/

## Features

- Live proof of the actual sheet layout (sidebar, photos 01–03, FRONT | LEFT | RIGHT | BACK turnaround, details) that updates as you type
- Three formats — Classic black, Clean white, Story 9:16 — previewed exactly as chosen
- 8 tag groups (same as the Telegram bot): body, skin, hair, eyes, face, look, wardrobe, vibe — plus your own custom tags in every group
- Height in cm or ft/in, weight in kg or lbs (converted for the prompt)
- Drag & drop up to 4 reference photos; color palette extracted from them
- Likeness strength, 1–3 variations, blank-text and turnaround-only options
- Batch: multiple characters as tabs, one zip
- Drafts autosave in your browser (photos are never stored or uploaded)
- Prompt tab, Copy & open Grok, native Share on mobile

## Usage

1. Fill in identity, tap tags (or add your own), drop in 1–4 photos
2. Pick format, likeness and variations
3. **Download zip** — `prompt.txt` + `photos/` (+ `palette.txt`)
4. A popup gives you a ready-made prompt — upload the zip as-is to ChatGPT (recommended), paste, send. Or drop the contents into Grok, Flux, Midjourney, etc. — or into the Grok skill (Path A)
